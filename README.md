# UART-Communicator
Program z GUI do komunikacji między dwoma hostami przy użyciu interfejsu RS232, stworzony na potrzeby przedmiotu IWSK Politechniki Śląskiej.
Program wymaga instalacji biblioteki pyserial dla języka Python.
